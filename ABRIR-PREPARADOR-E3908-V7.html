E-3908 — V7 consolidada

Refinamento do processo interativo da Desetanizadora: tela de processo maior no celular, lâmpadas alinhadas aos tags e remoção do painel “Selecione um equipamento”.

1. Gerar o index.html corrigido

O preparador lê o arquivo atual do GitHub, aplica somente as correções visuais e preserva integralmente o desenho, as explicações e os recursos V5.

Requer conexão à internet no navegador. O arquivo original nunca é alterado diretamente por este preparador.

Alternativa: se a conexão do navegador bloquear a leitura, selecione o index.html atual salvo em seu computador.

2. Publicar no GitHub

  1. Baixe o index.html gerado.
  2. Abra o repositório E-3908-concept.
  3. Use Add file → Upload files para substituir somente o index.html na raiz.
  4. Confirme Commit changes e abra a página da E-3908 no celular.

Não envie este preparador nem o ZIP ao portal central da Área Fria. Não precisa extrair ou modificar sw.js.

3. O que será ajustado

Proporção original 1280 × 917; margens reduzidas no mobile; zoom opcional; 11 lâmpadas calibradas a partir do desenho; painel técnico inicial removido e aberto apenas ao selecionar equipamento/atalho; botões de Conteúdo Integral e Laboratório dispostos em área própria, abaixo do desenho.

Aguardando geração.
