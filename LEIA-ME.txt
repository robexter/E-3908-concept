E-3908 CONCEPT — V7 CORRIGIDA, DIRETO PARA PUBLICAR
===============================================

O arquivo index.html desta pasta JÁ ESTÁ CORRIGIDO e inclui o desenho e as
explicações integrais. NÃO é preciso executar preparadores.

PUBLICAÇÃO (página ainda não muda automaticamente)
1) Abra https://github.com/robexter/E-3908-concept
2) Add file > Upload files
3) Arraste SOMENTE index.html desta pasta para substituir o existente na raiz.
4) Role até o fim e clique em Commit changes.

ATENÇÃO: O service worker atual usa CACHE-FIRST e tem CACHE_NAME antigo.
Mesmo depois da publicação, visitantes podem continuar vendo HTML antigo.
Para corrigir definitivamente também o cache:
5) No MESMO repositório, abra sw.js, clique no lápis (Edit this file).
6) Troque SOMENTE a primeira linha:
   const CACHE_NAME = 'e3908-concept-v1-concept-v5-52-mobile-20261015';
   POR:
   const CACHE_NAME = 'e3908-concept-v7-final-20261015';
7) Clique em Commit changes.
8) Reabra a página em https://robexter.github.io/E-3908-concept/?v=7-final
   Se estiver com PWA instalado, feche e reabra o app; se necessário, limpe
   os dados do site no navegador antes de testar.
